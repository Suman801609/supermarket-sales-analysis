# Supermarket Sales Analysis

## Project Description
This project performs exploratory data analysis on a Superstore sales dataset using Python. It analyzes sales, profit, quantity, product categories, regions, yearly/monthly trends, top products, and profit margins.

## Dataset
The project uses a CSV file named `supermarket_sales_clean.csv`.

Dataset source:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

Local dataset path:
`data/supermarket_sales_clean.csv`

## Dataset Information
- Rows: 9,994
- Columns: 21
- Missing values: 0
- Duplicate rows: 0

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Analysis
1. Dataset loading and exploration
2. Data cleaning
3. Sales and profit analysis
4. Category analysis
5. Region analysis
6. Year-wise sales trend
7. Month-wise sales trend
8. Top 10 products by sales
9. Profit margin by category
10. Final summary

## Key Results
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Total Quantity: 37,873
- Highest Sales Category: Technology
- Highest Profit Category: Technology
- Highest Sales Region: West
- Highest Sales Year: 2017
- Top Product: Canon imageCLASS 2200 Advanced Copier

## Setup and Run Instructions
1. Install Python 3.
2. Install required libraries:
   `pip install -r requirements.txt`
3. Keep the dataset at:
   `data/supermarket_sales_clean.csv`
4. Open `YourName_SupermarketSalesAnalysis.ipynb` in Jupyter Notebook or VS Code.
5. Run the cells from top to bottom.
